# blitzIT

Настольная утилита для мониторинга и управления машинами в локальной сети по IP.
Ведёт список адресов, показывает их доступность в реальном времени и позволяет
удалённо выключать хосты, подключаться по RDP и сканировать подсеть. Опционально
тем же управляет Telegram-бот.

WPF, .NET Framework 4.8, C#. Кодовое имя проекта в коде — `ServerBrowser`.

## Возможности

- **Мониторинг** — список IP с постоянной проверкой доступности пингом; строка
  зелёная/красная по статусу, при изменении статуса всплывает уведомление Windows.
- **Управление** — удалённое выключение (`shutdown /s`), отмена выключения
  (`shutdown /a`), подключение по RDP (`mstsc`) для выбранного хоста или для всех.
- **Сканирование** — обход подсети пингом с разрешением имён хостов.
- **Telegram-бот** (опционально) — те же действия с телефона: добавить/удалить IP,
  получить список, выключить хост.

Список адресов хранится в `items.json`, результаты сканирования — в `results.json`
рядом с исполняемым файлом.

## Настройка

Всё задаётся в [`App.config`](App.config) — секретов и адресов в коде нет.

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `BotToken` | пусто | Токен Telegram-бота. Пусто — бот не запускается |
| `ScanSubnet` | `192.168.0.` | Подсеть для сканирования, без последнего октета |
| `ShutdownDelaySeconds` | `100` | Задержка перед выключением удалённой машины |

Токен берётся у [@BotFather](https://t.me/BotFather) командой `/newbot`. Храните
его в секрете и не коммитьте в репозиторий.

## Сборка

Нужен .NET Framework 4.8 Developer Pack и MSBuild (Visual Studio 2019+). Зависимости
ставятся из NuGet при restore:

```
msbuild ServerBrowser.csproj /t:Restore,Rebuild /p:Configuration=Release
```

## Безопасность

Утилита рассчитана на управление **своими** машинами в доверенной локальной сети.
Перед использованием стоит знать:

- **У Telegram-бота нет авторизации.** Любой, кто найдёт бота и напишет `/start`,
  получает те же кнопки, включая «Выключить по IP». Если запускаете бота, держите
  его в секрете, а лучше — добавьте проверку `chat_id` отправителя по белому списку
  в [`TelegramBot.cs`](TelegramBot.cs). По умолчанию бот выключен (`BotToken` пуст).
- **Удалённое выключение** через `shutdown /m` и WMI работает только там, где у вас
  есть права администратора на целевой машине. Это не эксплойт, а штатный механизм
  Windows — но применять его к чужим хостам нельзя.
